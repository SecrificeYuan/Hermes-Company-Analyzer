# 设计规格 · 全站设计语言规范（双主题：LITE / PRO）

> 日期：2026-10-02 · 分支：`feat/design-language`
> 目标人群：金融专家（PRO）+ 普通大众（LITE），一套数据契约，两种呈现。

---

## 1. 背景与目标

现状设计为霓虹科幻游戏风（`#00E5FF` 主色 + 发光 + 扫描线 + HP/ATK 角色卡），用户反馈：游戏感过重、廉价感、层级不突出、对金融专家与普通人群两头不讨好。

**目标：**

1. 新增专业金融终端主题（PRO），达到"高级感、专业感"；
2. 现有霓虹主题保留并转正为大众主题（LITE），可更科幻、更游戏化；
3. 全站模式开关切换，术语与信息密度随模式变化，视觉各成体系；
4. 专业版引入高级可视化（瀑布图、Sparkline、桑基、波动带、双圈雷达），同类图表支持视图切换。

**非目标（YAGNI）：** 浅色主题；改动 `CompanyXRay` 数据契约；重写 `EChart.tsx` 核心 API。

## 2. 主题架构

```
lib/theme/
  themes/
    lite.ts        # 现有 token 原样迁入（霓虹科幻，可继续强化游戏化）
    pro.ts         # 新增金融终端 token（见 §3）
  echarts-lite.ts  # 现有 echarts-dark.ts 改名
  echarts-pro.ts   # 新增
  index.ts         # 按当前模式返回 token 集
```

- Tailwind 改为 **CSS 变量驱动**：`tailwind.config.ts` 颜色值引用 `var(--bg)`、`var(--accent)` 等；`app/layout.tsx` 根节点挂 `data-theme="lite|pro"`。
- 模式状态：zustand store（`mode: 'lite'|'pro'`，默认 `'lite'`），持久化 localStorage，切换时写 `document.documentElement.dataset.theme` 并触发 ECharts 主题重建。
- 模式只影响本机渲染层，**不改数据获取与契约**。

## 3. PRO 主题 Tokens（已视觉确认）

### 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0B0F1A` | 页面底 |
| `--card` | `#101625` | 卡片实底 |
| `--edge` | `#1E2A42` | 卡片描边 / 分隔线 |
| `--accent` | `#4C8DFF` | 唯一品牌点缀：按钮、选中态、图表主线 |
| `--safe` | `#3ECF8E` | 语义：低风险 / 正向 |
| `--warn` | `#FFB020` | 语义：关注 |
| `--danger` | `#FF5C6C` | 语义：高风险（较旧红降纯，去荧光感） |
| `--text` | `#F4F6FA` | 主文字 |
| `--text-dim` | `#8B94AB` | 次要文字 / 标签 |
| `--text-faint` | `#66738E` | 辅助说明 |

风险三色语义保持不变（`scoreColor` 阈值不动），仅色值替换。

### 禁用清单（PRO）

无发光阴影（`shadow-glow*` 不用）、无 `backdrop-blur`、无扫描线动画、无呼吸灯动画、无霓虹青。hover 仅边框色加深，无位移无发光。

### 字体与排版

- 标题/正文：Inter + PingFang SC（600 标题 / 400 正文），长文行高 1.7；
- 数字一律 `JetBrains Mono` 等宽（分数、金额、百分比、日期）；
- 大写标签：`font-size 11px · letter-spacing .1em · uppercase`（如 `HEALTH SCORE`、`综合评级 · AAA`）；
- 圆角统一 10px（卡片与按钮一致）；入场动画仅淡入 + 位移，stagger 0.05s 保留。

## 4. 双模式系统

### 切换机制

- 全站右上角 `LITE / PRO` 开关；zustand + localStorage；默认 `lite`；
- 首次进入报告页为 lite，可一键切换，刷新保持。

### 术语字典（文案按模式取值，组件内通过 `useMode()` 取词）

| 概念 | LITE（大众） | PRO（专家） |
|---|---|---|
| 综合分 | HP 血条 + 角色卡 | 基本面健康度 · 环形仪表 |
| ATK / DEF | 攻击 / 防御数值 | 增长动能 / 偿债安全垫 |
| 隐藏状态 | 负面状态（debuff）徽章墙 | 风险事件清单（严重度=颜色，表格化） |
| 情绪曲线 | 士气 Morale | 舆情指数 |
| 关系图谱 | 关联阵营图 | 股权 / 关联关系网络 |
| 诊断结论 | 一句话冒险式点评 | 结构化评级（AAA/AA/A…）+ 关键依据 |

### 信息密度

- **LITE**：结论优先、图表配大白话注解、部分模块详情折叠；
- **PRO**：全量模块、坐标轴标签齐全、来源角标常驻、指标表格嵌 Sparkline。

## 5. 组件规格

### 5.1 PRO 关键组件（已视觉确认）

- **评级结论条（VerdictBanner）**：`综合评级 · AAA` 大写标签 + 结论句（20px/600）+ 右侧 26px 等宽健康分 + 下方语义 chip（含数据来源角标）。
- **健康度仪表**：`conic-gradient` 环形进度 + 中心分数；右侧四维指标网格（数值 + ▲▼ 趋势箭头）。
- **风险事件清单**：两列表格（事件 · 日期），行分隔线，严重度用颜色；点击行开证据抽屉。
- **空态/错误**：沿用 `ChartEmpty`，PRO 下重 skin；断网、缺字段不崩版的要求不变。

### 5.2 高级图表（全部纳入，ECharts 实现）

| 图表 | 数据字段 | 说明 |
|---|---|---|
| 现金流瀑布图 | cashflow 系列 | 营收→成本→税费→净利悬浮柱，正负绿/红 |
| Sparkline | 指标序列 | 指标表格行内嵌 40px 折线 |
| 桑基图 | relations + 权重 | 与力导向图同组件切换（见 5.3） |
| 舆情面积图 + 波动带 | sentiment | 置信区间阴影，稀疏段变暗 |
| 双圈对比雷达 | attributes | 对比页，重叠弱化、差异高亮、逐项 diff 箭头 |

### 5.3 视图切换

- 关系图谱组件内置 `网络 ⇄ 桑基` 切换工具条；
- 现金流组件内置 `折线 ⇄ 面积 ⇄ 瀑布` 切换；
- 切换状态存组件本地 state，不做全局持久化。

### 5.4 分享卡

- LITE：沿用现有角色卡竖版；
- PRO：新增终端风格 1200×630（评级条 + 健康度环 + 风险清单摘要），导出逻辑（html2canvas）不变。

## 7. 验收标准

- [ ] 模式开关切换后全站主题即时生效，刷新保持；
- [ ] PRO 下无霓虹青/发光/扫描线残留（全站 grep 验证）；
- [ ] 数字全部等宽字体；风险三色语义在两主题下均一眼可辨；
- [ ] 关系组件可在力导向与桑基间切换且不丢数据；
- [ ] 3 家 mock 公司在两主题下渲染均不破版，空态正常；
- [ ] Lighthouse ≥ 80 不回归。

## 8. 风险与约束

- Tailwind 全量改 CSS 变量是最大机械改动，需一次性替换所有 `bg-ink-bg` 等类名映射；
- LITE 主题迁移过程中需冻结旧 token 文件改动，避免与 DOC-C 分支冲突（本分支基于 main，联调时按契约流程 rebase）；
- ECharts 主题切换需 dispose 重建实例，`EChart.tsx` 增加 `theme` prop 但不改其核心封装逻辑。
