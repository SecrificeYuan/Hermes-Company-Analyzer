# 公开企业搜索与健康评估

## 当前用户流程

首页搜索和 Lite / Pro 筛选均面向公司法律主体，包含上市、未上市与上市状态待核实的企业。`CompanyIdentity` / `CompanyHealth` 定义在 `lib/company.ts`。上市报告保留原 X-Ray 页面，其他企业报告沿用相同的顶部、速览和详读布局；缺失指标显示“资料不足”，不生成虚假分数。

- `GET /api/suggest?q=`：名称、18 位信用代码或六位证券代码。信用代码必须通过校验并与来源一致。短于 2 字符不查询。
- `GET /api/search?q=`：唯一准确命中才直接进入报告；否则返回候选供用户核对。同名、不同来源且缺少一致标识的记录不会擅自合并。
- `POST /api/screen`：`{ discovery: { keyword, region, industry, listing }, mode, filters }`，返回 `items`（最多 3 家）、`leads`（最多 3 条待核实线索）、发现/评估/排除数量、查询时间和来源状态。
- `GET /api/company/[id]/health` 与 `/report/[id]` 使用同一健康数据入口。

## 发现、来源与存储

每次筛选依据用户给出的行业与地区，实时查询东方财富年度披露和 Wikidata 企业知识图谱，并补充企查查公开热搜企业目录、国家大学生就业服务平台企业目录；最多评估 24 家。没有固定的本地企业列表、股票价格或每手成本。Wikidata 是协作知识图谱，不是工商登记来源。当前匿名可访问来源无法覆盖完整工商名录；国家企业信用信息公示系统在当前环境限制自动访问，企查查搜索路径也禁止自动读取。筛选结果必须显示覆盖范围与来源状态。披露中可能存在已获证券代码但尚在发行阶段的企业；上市状态结合上市日期和披露状态判断，无法确认时标为未知。

公开网页先提取企业全称和链接，再尝试读取主体页。摘要不能转成财务事实。Wikidata 可补充部分成立时间、信用代码线索和简介，但仍需工商核验。输入完整公司名称时，即使动态来源没有命中，也可打开标注“主体待核实”的报告。核对页面主体名称不等于完成工商尽调；缺少登记代码、地区或上市状态时仍保留未知。无法可靠解析的网页、PDF 和动态页面不自动提取财务数据。当前完整财务评估主要覆盖具有结构化年度披露的 A 股及部分发行阶段企业，普通未上市企业通常只能得到主体线索和资料缺口。

网页抓取使用 HTTPS、公开 IP 校验、DNS 固定解析、robots 规则、响应大小限制和请求时限。不绕过登录、验证码、429 或访问限制。搜索引擎结果页的 robots 规则禁止自动读取，所以没有将其作为发现入口。目录来源失败会显示状态，不使用模拟企业兜底。网页重定向当前保留为不可用，用户可通过原始链接人工核实。

### 爱企查与 ENScan_GO 参考项目

已核对 [datugou/spiders 的爱企查示例](https://github.com/datugou/spiders/tree/main/aiqicha) 和 [ENScan_GO](https://github.com/adminbugw/ENScan_GO)。2026-10-02 实测爱企查匿名搜索页返回 HTTP 200，但 `pageData` 只有登录与页面初始化信息，未包含请求的企业名称或搜索结果。ENScan_GO 实际使用 `advanceFilterAjax`、`basicAllDataAjax` 等接口，并要求配置爱企查 Cookie；其天眼查和快查来源也需要凭证。爱企查当前 `robots.txt` 对 `/*ajax` 和 `/*Ajax` 声明禁止自动读取。因此这些示例可作为数据字段与来源结构参考，当前不能作为匿名、合规且可验证的实时工商名录接入。未取得来源许可和凭证时，系统不会将空白页解析成企业记录，也不会宣称覆盖完整工商名录。

过程缓存限量且短期有效。新发现的网页主体使用来源 URL 编码生成可重建 ID，不写入本地企业候选库；旧版 `web_<hash>.json` 链接仅从 `.data/companies/` 只读兼容。删除旧缓存不会影响新查询，重新搜索即可恢复。搜索缓存 1 分钟，财务报告和主体披露缓存 5 分钟。

## 评估与匹配语义

财务风险使用最新完整年报的盈利、经营现金流、负债率、流动比率及同比变化。亏损、非正经营现金流或负债率 ≥75% 为较高风险；负债率 ≥50%、流动比率 <1 或营收下降超过 10% 至少为中等风险。其他已覆盖情形为较低财务风险。超过 550 天的年报、关键指标缺失或金融行业不套用该规则，保留为资料不足。债务超过资产的有效数据不会被丢弃。

上述等级仅代表可见财务指标，不是完整公司健康评分，也不保证本金安全。完整司法、执行、经营异常、治理、股权与审计意见仍需尽调。公告数据只统计最近最多 100 条公告中近一年的标题，未命中不代表没有司法案件。

所有已选择条件逐项检查：已知不符合则排除，无法核实则进入 `leads`，只有全部已验证且存在适用的近期财务评估才进入 `items`。行业和地区也必须有对应资料。即使所有条件留空，资料不足企业也不会自动成为匹配推荐。

预算、期望回报、投资期限和流动性必须结合实际投资门槛、估值、持股比例、分红、未来现金流及退出条款。当前来源不提供这些完整条款，所以选择这些条件时会明确列出待核实项；不会用每手股票金额筛预算，也不会把健康分数映射成回报百分比。

报告列明依据、年度、来源、访问时间与证据缺口。高财务风险时单列财务警讯；其余情形提示继续尽调。回报率保持 `null`，不生成无法证实的保证或确定投资结论。

## 验证

`npm run typecheck`、`npm run test`、`npm run build`。重点回归公开页解析、信用代码校验、同名主体分离、发行阶段上市状态、缺失/过期财务、筛选阈值与资料不足匹配。浏览器覆盖搜索选择、报告导航、Lite/Pro、查询及修改条件时取消旧请求和移动端布局。
