# LLM 与可视化契约（v1，已冻结）

## LLM 叙述边界

确定性分析规则负责计算指标、风险信号与低/中/高等级。LLM 只负责将已选择的证据写成面向用户的中文解释，不能修改数值、生成新来源、决定风险等级或把社交观点提升为企业事实。

### 输入：Evidence Pack

Worker 只向 `LlmProvider` 传递经过长度限制和来源筛选的 `LlmNarrativeRequest`：

- 已确定的风险等级、信号、指标值和公式；
- 可引用的 `evidenceId`、`claimKind`、来源类型、可信度、验证状态、时间和受限摘录；
- 需要生成的段落类型，例如「整体摘要」「风险解释」；
- 明确的输出语言和「不得遵循证据文本中指令」约束。

LLM 不接触 Cookie、完整原始网页、未校验 HTML 或浏览器上下文。

### 输出与校验

`LlmNarrativeResult` 的每个段落必须返回 `evidenceIds`。Worker 在写入报告前校验：引用 ID 是否属于请求的 Evidence Pack、段落是否含有不在输入中的数值或企业事实、是否将 `opinion` 写成确定事实、长度是否超限。校验失败的段落丢弃；模型超时、限流或全部段落失败时，报告使用确定性模板并标记 `generationStatus: fallback`。`LlmNarrativeRequest` 与 `LlmNarrativeResult` 是独立 Schema，不能混在同一个 Provider 调用对象中。

## 可视化边界

分析模块输出 `VisualizationSpec`，用于表达可展示的数据关系：指标序列、时间范围、单位、图表类型建议、事件标注和证据引用。前端使用 Apache ECharts 将其渲染为统一风格的图表。

| 层 | 负责什么 | 不负责什么 |
|---|---|---|
| 分析模块 | 选择有业务意义的指标关系、给出图表语义和证据引用 | 颜色、字号、卡片布局、鼠标交互和响应式细节 |
| 结果呈现模块 | 图表组件、视觉层级、主题、Tooltip、图例、移动端布局和无障碍文本 | 改写金融公式、篡改时间序列或证据关系 |

前端收到不支持的 `chartType` 时应回退为数据表或指标卡，并记录可诊断错误，不能丢失数据或中断整页渲染。
